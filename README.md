# Python Learning Workspace

One lesson = one folder.

## Folder Layout

- `00-setup/`: Python installation and VSCode setup.
- `01-basics/`: Printing, variables, data types, input/output, and operators.
- `02-control-flow/`: Conditions and loops.
- `03-data-structures/`: Lists, tuples, dictionaries, and sets.
- `04-functions/`: Functions, parameters, return values, and scope.
- `05-files-and-errors/`: Files, error handling, and JSON.
- `06-oop/`: Classes, objects, methods, attributes, and inheritance.
- `07-modules-and-tools/`: Imports, pip, and virtual environments.
- `08-projects/`: Independent practice projects.
- `review/`: Mistakes, cheatsheet, spaced review, and quiz log.
- `progress.md`: Status, scores, completion dates, and weak points for every lesson and project.

Every lesson folder contains `notes.md`, `examples.py`, `practice.py`, and `quiz.md`.
Every project folder contains `README.md`, `main.py`, and `notes.md`.
These files are placeholders to fill in as you learn.

## Workflow

1. Read and fill in the lesson's `notes.md`.
2. Add small examples to `examples.py` and run it with `python3 examples.py`.
3. Complete `practice.py` and run it with `python3 practice.py`.
4. Attempt `quiz.md` before filling in the answers and score.
5. Update `progress.md` with your status, quiz score, completion date, and weak points.
6. Record mistakes and schedule reviews in `review/`.

For projects, fill in the project README and planning notes, build in `main.py`,
and update the project row in `progress.md`.

Use the Python standard library for this workspace; no packages need to be installed.
